品牌简介

azi加速器（简称 azi）是一套以订阅为核心的网络加速服务。用户在官网选定套餐后获取订阅地址，再在 Windows、macOS、Android、iOS 或常见开源客户端中导入，即可按延迟与用途切换节点。服务定位覆盖日常网页加速、会议协作、流媒体点播与对延迟敏感的游戏线路，而不是一次性试用节点列表。

与散落的临时配置相比，azi 将流量配额、同时在线设备数和线路等级写进套餐，方便按月或按年续订。旗舰版强调原生流媒体解锁与 IPLC 游戏向优化，团队版则把带宽与设备上限交给多人共用。本站仅提供官方说明与下载指引，请从本页锚点进入对应章节，避免来路不明的安装包。

使用场景

跨境办公与协作

远程桌面、代码仓库、云文档和视频会议对丢包更敏感。基础版即可覆盖常规网页与会议；文档往来频繁或需要同时挂多台电脑时，可直接看旗舰版的五设备额度。

流媒体与内容站点

点播、直播和地区版权库依赖出口质量。旗舰版写明全节点原生流媒体解锁，适合把播放器固定在同一条线路上，减少反复换节点。基础版提供基础解锁，适合偶尔观看。

游戏与实时对战

旗舰版含 IPLC 专线游戏加速优化，用于把延迟曲线压得更平。团队训练或工作室多开时，团队版的高带宽节点和定制路由更合适，不必把个人套餐硬分给二十台设备。

操作说明

从开通到第一次连通

  1. 在订阅套餐中选定基础版、旗舰版或团队版，完成开通后复制机场订阅地址。
  2. 打开对应系统的客户端下载入口，安装 azi 官方客户端或你已熟悉的兼容客户端。
  3. 在客户端选择「订阅 / 从 URL 更新」，粘贴地址，确认节点列表出现多地区线路。
  4. 按用途挑选节点：网页与文档选延迟较低的综合节点；播放选标注流媒体的出口；对战游戏优先旗舰版 IPLC 相关线路。
  5. 开启连接后访问目标站点。若页面长时间无响应，切换相邻地区节点，并确认本地系统时间准确。

日常维护

建议每周手动更新一次订阅，以免节点变动后仍使用旧配置。流量将尽时客户端会提示配额，基础版可考虑升级到旗舰版而不是频繁更换服务。多设备登录时，以套餐同时在线数为上限，超出后新会话可能被踢出。

线路与加速能力

azi 节点池按套餐分层。基础版使用普通线路节点池，覆盖常用地区，满足浏览与基础解锁。旗舰版在此之上提供原生流媒体出口，并对游戏向 IPLC 线路做延迟优化。团队版另开 VIP 高带宽节点，允许按企业网段做定制路由，把办公网段与娱乐网段分开。

实际速度受本地宽带、时段拥堵和目标站策略影响。同一套餐内可随时换节点，不必改订阅地址。若某条线路持续失败，优先更新订阅；仍异常再走旗舰版与团队版的工单或客户经理通道。

常见问题

以下问题按开通、下载、套餐和排障顺序排列。点开即可阅读完整说明，无需离开本页。

azi加速器是什么？和普通 VPN 客户端有何关系？

azi加速器是带流量配额的机场订阅服务，azi VPN 客户端用于导入该订阅并建立加密隧道。你也可以把同一订阅贴进其他兼容客户端。核心差别在于节点与配额由 azi 套餐管理，而不是只提供单一服务器。

如何从官网下载客户端并导入机场订阅？

先在本页完成套餐开通并复制订阅地址，再进入「客户端下载」按系统安装。打开软件后选择从 URL 添加订阅、保存并更新，节点出现后即可连接。不要使用来源不明的安装包，以免订阅被第三方截获。

基础版、旗舰版和团队版应该怎么选？

轻度使用、三台设备以内选基础版（¥15/月或 ¥150/年，100GB）。需要原生流媒体、游戏向 IPLC 和五台设备选旗舰版（¥35/月或 ¥350/年，300GB）。二十台设备、千 GB 流量或要定制路由时选团队版（¥85/月或 ¥850/年）。年付按十二个月计，适合确定会长周期使用的情况。

支持哪些系统？同时在线设备数如何计算？

桌面覆盖 Windows 与 macOS，移动覆盖 Android 与 iOS，另兼容常见订阅客户端。基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。电脑、手机、平板各算一台；同一账号在超限设备上新建连接时，最早会话可能被断开。

流量如何统计？用尽或连接失败时怎么办？

套餐流量按出站实际用量累计，月度重置。接近上限时减少大文件与长时间 4K 播放，或升级套餐。连接失败时依次检查：订阅是否已更新、系统时间是否正确、是否超出设备数、本地防火墙是否拦截虚拟网卡。更换同区域其他节点通常即可恢复。

流媒体解锁和游戏加速怎样才生效？

基础版提供基础流媒体解锁，能覆盖部分平台；旗舰版要求选择带原生解锁标记的节点，并避免在播放中途频繁跳转地区。游戏请使用旗舰版 IPLC 相关线路，关闭游戏自带加速再测延迟。团队版可按域名把游戏与办公分成不同出口。
